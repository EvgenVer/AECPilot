# Optional interview coverage

Use only unanswered dimensions that affect the user's decision:
- Purpose and intended audience.
- Concrete success/acceptance examples.
- Constraints and non-goals.
- Main user scenario and important failure cases.
- Unresolved technical, data, permission, or cost boundaries.
- For AI behavior: expected outcomes, unacceptable actions, and evaluation needs.

Ask one understandable decision at a time or a small related batch. Reuse existing
answers, explain choices plainly, and follow the host's question interface. Do not
treat this list as a mandatory questionnaire or equate passing tests with user success.
