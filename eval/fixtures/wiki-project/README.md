# Мини-проект для эвала вики (задача 4.14)

Шесть документов, придуманных целиком. Настоящий эталонный проект для этого
эвала не годится по двум причинам, и обе выяснились измерением:

1. **Материал слишком велик.** Десять фрагментов настоящего проекта — это
   297 тысяч знаков; судья, которому дают такой объём, судит по тому куску,
   что поместился, и объявляет выдумкой всё остальное. На мини-проекте
   материал целиком помещается и в модель, и в судью.
2. **Противоречия там может не быть.** Сценарий «две редакции с разными
   числами» нельзя проверять надеждой, что такая пара найдётся: здесь она
   заведена нарочно — 250 кВт в первой редакции против 320 кВт во второй.

Факты придуманы, но правдоподобны. Ни один документ не списан с настоящего.
