# Пояснительная записка. Раздел «Конструктивные решения»

Объект: производственный корпус №3, площадка «Северная».

## Каркас

Каркас здания — стальной, по серии 1.420-12.
Колонны каркаса — двутавр 30К1, сталь С255.
Балки покрытия — двутавр 45Б2, сталь С255.

## Шумозащитный экран

Вдоль северной границы площадки предусмотрен шумозащитный экран.
Несущими элементами экрана являются стойки из двутавра 20Ш1, сталь С235.

Подземной автостоянки на объекте не предусмотрено.
