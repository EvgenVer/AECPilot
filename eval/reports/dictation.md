# Замер диктовки (T58), 2026-11-24

Вопрос: годится ли местное распознавание речи ядра (faster-whisper) для инженерной диктовки и
какую модель брать по умолчанию.

## Как мерили

- 10 записей владельца (`eval/samples/dictation`, в git не попадают), 74 с речи, эталон —
  `eval/dictation-phrases.md`. Стенд — `eval/dictation_bench.py`: распознаёт **код ядра**
  (`tools.voice_mode.transcribe_recording`) с `stt.provider: local`, `stt.language: ru`;
  параметры — умолчания ядра (beam 5, VAD, без контекста прошлого куска).
- Процессор i7-12650H, int8, без видеокарты, без сети. Бесплатно.
- **Верно терминов** — сколько из 49 терминов, чисел и обозначений записаны так, что править не
  надо. **WER** — доля слов с ошибкой. Повтор на той же настройке — ±1–2 термина.
- «Словарь» — подсказка ядра `stt.local.initial_prompt` с общими терминами КР
  (`eval/dictation-vocabulary.txt`), составлена не по фразам замера.

(medium 20–40 с на фразу): машина была занята другой работой. Число потоков (4 или 8) разницы
не даёт.

## Что видно по тексту

- medium пишет обычные фразы почти без правки: «Найди в разделе КЖ узел сопряжения монолитной
  стены с плитой перекрытия», «Нагрузка на перекрытие постоянная 4,5 кПа, временная 2 кПа».
- Ни одна модель не взяла: «плюс двенадцать шестьсот» (пишет 12600), «шаг двести» (пишет 2),
  «балки Б-3 по СП 63.13330» (слипается), «в осях А–В / 1–4», «по двутавру 30Б1». Часть из
  этого может быть особенностью записи: проверить это без владельца нельзя.
- **Словарь опасен обозначениями.** В нём был «двутавр 20Ш1» — и обе модели вместо «30Б1»
  написали «30Ш1»: правдоподобное, но неверное сечение. Без словаря ошибка хотя бы заметна
  («30%», «Ру-30»). Если словарь брать, то без обозначений. У medium он пользы не даёт.

## Вывод

Местное распознавание годится как черновик: текст встаёт в поле, человек читает его перед
отправкой; числа и обозначения проверять обязательно. По умолчанию — **medium без словаря**:
лучше всех по терминам и заметно лучше small по словам. Цена — 5–6 с ожидания после фразы
(на занятой машине в разы больше) и 1,8 ГБ памяти, пока модель загружена.

Не замерено: large-v3-turbo (≈1,6 ГБ — размер как у medium, архитектура новее) и видеокарта
(нужны библиотеки NVIDIA, в поставку не входят).
