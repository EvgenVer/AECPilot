# Фразы для замера диктовки (T58)

Начитайте каждую фразу отдельным файлом обычным голосом и в обычном темпе, как диктовали бы
агенту. Подойдёт любой диктофон: телефон, «Запись голоса» Windows, гарнитура. Формат — любой
(m4a, mp3, wav, ogg). Имя файла — номер фразы: `01.m4a`, `02.m4a`, …

Положите файлы в папку `eval/samples/dictation/` (в git она не попадает — записи остаются
только на этой машине). Если в фразе удобнее сказать иначе («диаметр двенадцать» вместо
«Ø12»), так и говорите — текст ниже нужен как эталон для сравнения, а не как скороговорка.

1. Армирование плиты перекрытия на отметке плюс двенадцать шестьсот: нижняя сетка из
   арматуры А500С диаметром двенадцать с шагом двести.
2. Проверь прогиб балки Б-3 по СП 63.13330 при пролёте шесть метров.
3. Защитный слой бетона для фундаментной плиты принять пятьдесят миллиметров.
4. Класс бетона колонн в осях А–В / 1–4 — B30, марка по морозостойкости F150, по
   водонепроницаемости W6.
5. Найди в разделе КЖ узел сопряжения монолитной стены с плитой перекрытия.
6. Нагрузка на перекрытие: постоянная четыре и пять десятых килопаскаля, временная два
   килопаскаля, коэффициент надёжности один и два.
7. Сравни спецификацию металлоконструкций КМ с ведомостью расхода стали по двутавру 30Б1.
8. Шаг поперечной арматуры в колонне сто пятьдесят, хомуты из А240 диаметром восемь.
9. Отметь в замечаниях, что продавливание плиты у колонны К-7 не проверено.
10. Расчётная модель в ЛИРЕ: пересчитай РСУ после изменения жёсткости диафрагм.
