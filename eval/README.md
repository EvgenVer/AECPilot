# eval — измерения и эвалы

Здесь живут материалы и отчёты замеров фазы 2 и дальше (`docs/plan-details.md` §Validation strategy).

## Что коммитится, а что нет

| Путь | В git | Почему |
|---|---|---|
| `eval/samples/**` | **нет** (`.gitignore`) | настоящие проектные документы — чужая интеллектуальная собственность и лишние мегабайты в истории |
| `eval/qa_dataset.yaml`, `eval/runner/**` | да | наш датасет вопросов и раннер (задача 2.16) |
| `eval/ocr-report.md`, `eval/load-report.md`, `eval/reports/**` | да | отчёты замеров — они и есть результат работы |
| `eval/qa_seed.yaml`, `eval/qa_review.md` | да | рукописные вопросы и лист проверки владельцем (2.16a) |
| `eval/fixtures/**` | да | документы, которые мы делаем сами: без них часть датасета не прогнать на свежем клоне |
| `eval/variants/**` | да | правила-добавки, которыми меряются плечи A/B: разница между плечами обязана быть видна отдельным файлом (3.22) |
| `eval/fixtures/wiki-project/**` | да | мини-проект для эвала вики: шесть придуманных документов. Настоящий проект для него не годится — материал в 297 тыс. знаков судья видит кусками и объявляет выдумкой всё остальное (4.14) |

Каталоги `eval/samples/` в свежем клоне нет: git не хранит пустые каталоги, а
содержимое игнорируется. Создать её заново — `mkdir -p eval/samples/scans eval/samples/project`.

## Куда что класть

### `eval/samples/scans/` — сканы для замера OCR (задача 2.2)

PDF **без текстового слоя**: фотография или скан бумаги. Нужно ≥5 штук, и чем
«злее», тем полезнее — с наклоном, печатями, штампами, рукописными пометками,
слабым контрастом. На чистом ровном скане движки не различаются, и замер, ради
которого задача существует, не состоится.

### `eval/samples/project/` — документы эталонного проекта (задачи 2.8–2.12, 2.16)

Обычные PDF с текстовым слоем, DOCX, XLSX/CSV. На них строится индекс и потом
датасет из ≥30 вопросов. Ценно, чтобы документы были **связаны между собой**
(задания смежников, ведомости, пояснительная записка) и чтобы среди них нашлись
**две редакции одного задания с разными числами** — сценарий «противоречащие
редакции» из `docs/history/specs/qa-over-sources.md` иначе проверить нечем.

Структура внутри произвольная: индексер обходит дерево целиком и хранит
относительные пути.
