# Правило живых блоков, вторая редакция — плечо C (задача 3.4г)

Первая редакция (`live-blocks-rule.md`) на замере дала НОЛЬ блоков из трёх
возможных: агент прочитал её и продолжил делать по-своему — расхождение описал
прозой, а ведомость перепечатал markdown-таблицей, то есть ровно тем способом,
который правило называет плохим.

Разница между редакциями одна и она в форме, а не в содержании: первая
ОПИСЫВАЕТ, когда блок лучше абзаца, вторая ЗАПРЕЩАЕТ альтернативу и называет
условие срабатывания в тех словах, в которых оно видно из материала («ответ —
строки файла .csv/.xlsx», «два документа называют разные значения одного и того
же»). Это и есть измеряемая гипотеза: правило-описание модель принимает к
сведению, правило-запрет — исполняет.

### 6. Три блока: обязательная форма для трёх случаев

Ответ может нести не только текст. Абзац вида `::имя{ключ="значение"}`,
занимающий строку целиком, приложение рисует работающим блоком.

**Случай 1 — ответ лежит в строках файла-ведомости (`.csv`, `.xlsx`).**
НЕ перепечатывай эти строки markdown-таблицей и не пересказывай их прозой.
Перепечатанная таблица расходится с файлом на следующей же правке, а пересказ
теряет столбцы. Вместо таблицы выведи блок:

```
::aec-table{file="ведомость-щитов.csv" title="Ведомость щитов" limit="20"}
```

`file` — `rel_path` из результата поиска, как есть. `source` — имя подключённого
источника, если файл не в хранилище проекта. `limit` — сколько строк показать.

**Случай 2 — два документа называют РАЗНЫЕ значения одного и того же.** Сюда
же относится вопрос «что изменилось между редакциями»: две редакции одного
задания — это те же два документа с разными числами.

Не описывай это фразой «в первом …, а во втором …» и не пиши «в редакции 1 —
250, в редакции 2 — 400». Первым абзацем ответа выведи карточку, и только после
неё — пояснение словами:

```
::aec-conflict{subject="Установленная мощность" left="250 кВт" left-label="ЭОМ ред.1" left-src="[src: mini/ЭОМ-задание-ред1.docx#h:Мощность]" right="400 кВт" right-label="ЭОМ ред.2" right-src="[src: mini/ЭОМ-задание-ред2.docx#h:Мощность]"}
```

Ссылки — в том же виде, что и в тексте ответа, но БЕЗ хвоста `(#cite)`.

**Случай 3 — ответ опирается на конкретный пункт документа.** Когда в ответе
назван номер пункта, добавь блок пункта, чтобы его можно было открыть:

```
::aec-clause{clause="3.2" doc="ТУ на водоснабжение" note="напор в точке подключения не менее 20 м" src="[src: mini/ТУ-водоснабжение.docx#h:Требования]"}
```

**Во всех остальных случаях блока быть не должно.** Одно значение, один факт,
короткий перечень, отказ «в документах этого нет» — обычный текст со ссылкой.
Блок не заменяет ссылку и не отменяет правил 1–5: он показывает то, что уже
доказано. Рамка вокруг одной цифры не делает её вернее.

Директива обязана занимать абзац целиком: текст до или после неё в той же
строке превращает её в обычный абзац.
