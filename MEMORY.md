- **`awk '/\r$/'` НЕ ВИДИТ CR на этой машине** — Git Bash отдаёт awk строки уже без `\r`, и проверка концов строк через него всегда отвечает «ноль», даже когда файл наполовину CRLF. Слепая проверка хуже отсутствующей: по ней я трижды за сессию подтвердил чистый LF в файле со 106 CR. Верные инструменты: `git ls-files --eol <файл>` (показывает и индекс, и рабочую копию) и `python -c "b=open(f,'rb').read(); print(b.count(13), b.count(10))"`. - **Обычная установка Hermes на этой же машине — допустима, и вот что она делает** (проверено по их `install.ps1`, 2026-09-15, D-87): пишет `HERMES_HOME=%LOCALAPPDATA%\hermes` в переменные ПОЛЬЗОВАТЕЛЯ, добавляет `hermes` в PATH, ставит свой Node 22 первым в PATH только если системный ниже порога (22.22+ / 24.11+ / 26+).
