# AECPilot — быстрый старт

AECPilot — рабочее место инженера-проектировщика с агентом. Вы подключаете папки с
исходными данными проекта (задания смежников, ТУ, письма), приложение строит по ним
индекс, а агент отвечает на вопросы со ссылками на документы: щелчок по ссылке
открывает документ на нужной странице.

## Что нужно

- Windows 10 или 11, 64 бит.
- Около 4 ГБ свободного места под программу и ещё место под данные и индексы проектов.
- Ключ API провайдера модели (например, Google Gemini) или подписка, которую
  поддерживает мастер первого запуска.
- Python, Node.js и Git ставить не нужно — всё нужное уже внутри установки.

## Установка

1. Запустите `AECPilot-<версия>-win-x64.exe`.
2. **Окно SmartScreen.** Установщик не подписан, поэтому Windows может показать
   «Система Windows защитила ваш компьютер». Нажмите «Подробнее», затем
   «Выполнить в любом случае».
3. Выберите папку установки. **Всё, что приложение пишет, остаётся в этой папке:**
   программа, среда агента, а в подпапке `data` — чаты, память агента, настройки,
   ключи моделей и расписания. В профиль пользователя и `AppData` приложение не пишет.
   Права администратора не нужны; папка должна быть доступна вам на запись.
4. Выберите режим:
   - **Всё на этом компьютере** — обычный выбор для одного рабочего места.
   - **Только сервер** — ядро агента и индекс работают в фоне при входе в систему,
     без окна. Подходит для машины, на которой лежат документы.
   - **Только приложение** — компьютер подключается к серверу AECPilot; своего ядра
     и индекса на нём нет.
5. Дождитесь конца установки. **Она долгая:** установка начисто и обновление поверх
   прежней версии занимают от 15 минут до часа. В поставке около 100 тысяч файлов,
   и антивирус проверяет каждый — время зависит от него больше, чем от компьютера.
   Это нормально, установщик не завис.

Тихая установка (для администраторов):
`AECPilot-<версия>-win-x64.exe /S /MODE=full /D=C:\AECPilot` (режимы `full`, `server`,
`client`; `/D=` — последним аргументом, без кавычек).

## Первый запуск

1. Откройте AECPilot с ярлыка. Мастер первого запуска предложит выбрать провайдера
   модели и ввести ключ. Ключ хранится в папке `data` установки.
2. **Создайте проект:** выберите папку проекта. В ней агент ведёт заметки и вики, а
   служебные файлы проекта лежат в подпапке `.aecpilot` — в том числе индекс.
3. **Подключите источники:** в боковой панели «Источники» → «Подключить папку».
   Источник — папка с исходными данными; агент её только читает.
4. **Проиндексируйте:** страница «Индекс» → «Проиндексировать». Пока идёт
   индексация, виден её ход; первая индексация большого проекта занимает время.
   Дальше приложение само проверяет источники по расписанию и замечает новые файлы.
5. **Задайте вопрос** в чате, например: «Какая расчётная нагрузка щита ЩС-1?».
   В ответе будут ссылки на документы; щелчок по ссылке открывает документ на
   нужной странице.

## Сервер и подключение к нему

Сервер ставится в режиме «Только сервер» на машину, где лежат документы. Он
запускается сам при входе пользователя в систему и показывает значок в трее:

- «Скопировать токен подключения» — токен для клиентов. Токен постоянный: он
  переживает перезапуск сервера.
- «Выдать новый токен» — старый перестаёт действовать, клиентам нужен новый.
- «Остановить сервер».

Шлюз сервера слушает только `127.0.0.1:18789` — из сети он не виден. Клиент
подключается к нему через SSH-туннель:

```bash
ssh -N -L 18789:127.0.0.1:18789 пользователь@сервер
```

Затем в приложении на клиенте: «Настройки» → «Шлюзы» → «Удалённый шлюз», адрес
`http://127.0.0.1:18789` и токен с сервера. После этого проект открывается на диске
сервера: папку проекта и источники вы выбираете в окне, которое показывает диск
сервера, а индексирует и сканирует источники сервер — в том числе когда ноутбук
закрыт. Индекс остаётся на сервере.

## Обновление

Когда выйдет новая версия, приложение покажет уведомление с кнопкой «Скачать».
Запустите новый установщик и укажите ту же папку: данные из `data` и индексы
проектов сохранятся.

## Удаление

«Параметры» → «Приложения» → AECPilot → «Удалить». Перед удалением установщик
покажет, что будет удалено. Две галочки (по умолчанию выключены):

- «Удалить и мои данные» — папка `data`: чаты, память агента, настройки, ключи,
  расписания. Если её не отмечать, при повторной установке в ту же папку всё вернётся.
- «Удалить индексы проектов» — папки `.aecpilot` в перечисленных проектах.

Ваши документы и папки проектов не удаляются никогда. Для режима «Только сервер»
удаление снимает и задачу автозапуска.

## Если что-то пошло не так

- **Установка идёт очень долго** — см. выше: до часа — нормально.
- **Сервер не отвечает клиенту** — проверьте значок в трее на сервере («Сервер AECPilot
  работает»), что туннель SSH поднят и что токен скопирован после последней выдачи.
- **Журналы** лежат в `<папка установки>\data\userData\logs` и
  `<папка установки>\data\profile\logs`.
