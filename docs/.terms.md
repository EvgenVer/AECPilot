*[MCP]: Model Context Protocol — протокол, по которому агент получает инструменты от внешних серверов
*[IPC]: межпроцессное взаимодействие Electron: окно вызывает главный процесс по имени канала
*[JSON-RPC]: протокол вызовов «метод + параметры → результат» в формате JSON
*[RRF]: reciprocal rank fusion — слияние ранжированных списков по сумме 1 / (60 + место)
*[FTS5]: полнотекстовый поиск, встроенный в SQLite
*[OCR]: распознавание текста на изображении страницы
*[NSIS]: система сборки установщиков Windows
*[PM]: менеджер пакетов ядра: собирает его переносимую среду для поставки
*[LightRAG]: библиотека индекса: векторы фрагментов и граф знаний в файлах проекта
*[Docling]: библиотека разбора документов DOCX, XLSX, CSV
*[RapidOCR]: движок распознавания текста на onnxruntime, модель eslav
*[Mem0]: библиотека долговременной памяти агента: факты с датой и поиск по смыслу
*[safeStorage]: шифрование Electron средствами ОС (DPAPI на Windows)
*[payload]: заранее собранная переносимая среда в установщике: ядро или наш Python
*[preload]: скрипт Electron, публикующий окну ограниченный API поверх IPC
*[vault]: папка проекта: заметки, вики, черновики и служебная .aecpilot/
*[A2A]: протокол «агент — агенту», внешний канал, выключен по умолчанию
