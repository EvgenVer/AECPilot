# 0015 — Лицензия продукта и правила лицензий зависимостей

- Date: 2026-07-06 (только permissive); 2026-08-05 (CC-BY-4.0 для ассетов); 2026-10-16
  (GPL отдельной программой); 2026-10-19 (LGPL/MPL в Python MCP); 2026-10-22 (A8)
- Status: accepted
- Approved by: owner

## Context

Модель распространения держим открытой, включая коммерческую (C3). Поставка везёт
стороннее: Python-окружения, Node, Chromium, Git for Windows (на Windows ядро выполняет
каждую команду терминала агента через его bash, снимки UR14 хранятся в git), иконки
`@vscode/codicons` под CC-BY-4.0.

## Options

### Закрытая бесплатная программа; зависимости permissive, узкие оговорённые исключения — chosen

- Advantages: продукт остаётся в руках владельца; поставка законна и описана.
- Limitations: каждая зависимость проходит веттинг лицензии; `pillow-heif` (GPL в колесе) не
  ставится — HEIC/HEIF-фото ядро отклоняет понятной ошибкой.
- Changing it later: costly.

### Открытая лицензия продукта

- Limitations: не выбрана владельцем.

## Decision

AECPilot — закрытая бесплатная программа: пользоваться бесплатно, код не публикуется,
копировать и переделывать нельзя; правообладатель — владелец как физлицо (`LICENSE.txt`).
Зависимости — MIT/Apache-2.0/BSD/ISC; CC-BY-4.0 — только для не-кодовых ассетов с указанием
авторства. AGPL/GPL исключены; единственное исключение — отдельная неизменённая программа,
которую ядро запускает процессом (Git for Windows, с лицензией, ссылкой на исходники и
письменным предложением выслать их в течение трёх лет). Неизменённые LGPL-библиотеки внутри
колёс, подключаемые динамически (GEOS в `shapely`, FFmpeg в `opencv-python`), и пакеты под
MPL-2.0 (`certifi`, `pathspec`, `tqdm`) допущены. ffmpeg в GPL-сборке не поставляется.

## Consequences

- `THIRD-PARTY-NOTICES.txt` собирается сборкой (`apps/desktop/third-party-notices.cjs`),
  открывается из программы командой палитры.
- Правообладатель и контакт для предложения по Git — `apps/desktop/package.json`
  (`aecpilot.copyrightHolder`, `aecpilot.sourceOfferContact`); сборка установщика
  останавливается, пока правообладатель пуст.
- Подробно — [PRODUCT.md](../PRODUCT.md) C3, A8; [plan-details.md](../plan-details.md)
  §«Selected dependencies».
