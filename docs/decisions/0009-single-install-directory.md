# 0009 — Всё в одном каталоге установки

- Date: 2026-09-15 (UR40, AC14); устройство — 2026-10-19 (T30, T38–T41)
- Status: accepted
- Approved by: owner

## Context

Донор раскладывает файлы по каталогам пользователя (`%APPDATA%`, `%LOCALAPPDATA%\hermes`,
`~/.mem0`, `~/.cache`). На машине владельца рядом может стоять обычная установка Hermes:
общие пути означали бы общий журнал mem0 и общие блокировки шлюза (замечено: шлюз отдельного
Hermes гасил наши рутины, D-164).

## Options

### Всё под одним выбранным каталогом `<root>` — chosen

- Advantages: соседство с Hermes без конфликтов; удаление стирает ровно своё; переносимая
  сборка (zip) не оставляет следов вовсе.
- Limitations: каждый писатель вне корня надо найти и закрыть переменной окружения или
  настройкой; данные нельзя класть в `Program Files` — умолчание установщика — каталог
  пользователя.
- Cost and effort: четыре рычага (каталог установки, `userData` Electron, `HERMES_HOME`,
  кэши) и проверка AC14 снимком дерева.
- Changing it later: costly.

### Стандартные места Electron и ядра

- Limitations: конфликт с обычной установкой Hermes, мусор после удаления.

## Decision

Под `<root>`: приложение, `runtime/` (наш слой, payload ядра `runtime/core`, Python MCP
`runtime/mcp`), `plugins/`, `skills/` и `data/` — всё, что пишет продукт: `userData` (с
`sessionData`, журналами, дампами), профиль ядра `profile`, `tmp`, `cache` (`XDG_CACHE_HOME`,
`HF_HOME`), `npm`, список индексов проектов `index-locations.txt`. Переключает
`main/data-root.ts` первым импортом главного процесса; признак установки —
`runtime/core/manifest.json` без `.git`. Снаружи остаются только ярлык и запись в «Удалении
программ». Документы и vault пользователя — там, где он их держит.

## Consequences

- Удаление показывает перечень; `data` и индексы проектов стираются только по галочкам
  (по умолчанию выключены) и никогда при обновлении (`build/installer.nsh`,
  `customRemoveFiles`).
- Все запуски ядра передают `HERMES_HOME`, `MEM0_DIR`, `HERMES_GATEWAY_LOCK_DIR` явно.
- Подробно — [plan-details.md](../plan-details.md) §«Установка в один каталог»,
  [данные](../data.md).
