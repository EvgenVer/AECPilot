# 0013 — Провайдера моделей выбирает пользователь

- Date: 2026-09-28 (находка D-154); 2026-10-02 (отдельный выбор для индекса и памяти, D-172)
- Status: accepted
- Approved by: owner

## Context

Изначально индекс (`aec-rag`) и память (Mem0) зашивали свои модели и адрес OpenAI
(`text-embedding-3-large`, датированный снимок модели извлечения). У организаций бывают
закрытые контуры; vendor-независимость обязательна (C5). Агент может работать по подписке
(вход через браузер, например Codex) — у подписки нет адреса с ключом, которым могли бы
пользоваться наши модули.

## Options

### Провайдер — выбор пользователя; у индекса и памяти свой выбор, по умолчанию «как у агента» — chosen

- Advantages: ни один наш модуль не зашивает провайдера; работает по подписке; переход в
  закрытый контур — настройка.
- Limitations: смена модели эмбеддингов означает перестройку индекса, а факты памяти,
  записанные с прежней моделью, не видны, пока она не возвращена.
- Changing it later: easy.

### Зашитый провайдер (OpenAI)

- Limitations: чужой ключ и чужой счёт; против C5.

## Decision

Индекс (эмбеддинги и модель разбора для графа), память (модель и эмбеддинги) и генерация
картинок берут адрес, ключ и модели из выбора пользователя через OpenAI-совместимый адрес.
Настройка «Индекс и память» задаёт провайдера отдельно для поиска и для памяти; по умолчанию —
«как у агента». Мастер первого запуска провайдера по умолчанию не предлагает; при подписке он
просит выбрать провайдера для индекса и памяти явно. Без выбора индексация и память
отказывают словами со ссылкой на настройку — молча другой провайдер не подставляется.

## Consequences

- Приложение предупреждает о перестройке индекса до сохранения новой модели эмбеддингов.
- Стенд автотестов берёт провайдера из своей конфигурации (сейчас Gemini).
