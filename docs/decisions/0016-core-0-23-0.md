# 0016 — Версия 0.2: подъём ядра на v0.23.0

- Date: 2026-11-07 (разбор выпуска и интервью владельца)
- Status: accepted (сменит пин 0.22.2 из решения [0012](0012-core-0-22-2.md), когда этап
  подъёма будет закрыт)
- Approved by: owner

## Context

Hermes Agent v0.23.0 «The Hearth Release» вышел 2026-11-05 (`2bd378ed`), между ним и нашим
пином 0.22.2 — 8170 коммитов. Главное для нас: групповые чаты ведёт ядро (их окно перешло на
`groups.*` — условие возврата HX18), один шлюз владеет каждым сеансом, делегирование стало
подключаемым, у MCP появились цена вызова, живой прогресс и честные подтверждения. В зоне
донора изменились 568 из 1764 вендоренных файлов, у 111 наших файлов правки придётся
наложить заново. Полный разбор — [следующая версия](../next-version.md).

## Options

### Поднять на `v0.23.0` и перенять логику ядра — chosen

- Advantages: групповые чаты, субагенты и MCP работают так же, как у Hermes; меньше своего
  кода, который пришлось бы держать против течения ядра.
- Limitations: этап размером с прошлый подъём; прежние групповые комнаты становятся
  только для чтения; ядро убрало инструменты `browser_*`, `agent-browser`, mermaid.js и 14
  встроенных навыков — отказываемся вместе с ним.
- Cost and effort: этап 5 в [TASKS](../TASKS.md).
- Changing it later: costly.

### Остаться на 0.22.2 и держать свой групповой чат

- Limitations: их окно больше не ведёт круг само — старый путь у `hermes serve` фактически
  недоступен без правок вне шести разрешённых; отставание растёт.

## Decision

1. Пин — стабильный `v0.23.0`; правило объёма прежнее: всё, кроме закрытого списка.
2. Групповые чаты — на логике ядра, без готовых команд (UR47); HX18 отменён.
3. Одно подключение за раз остаётся (HX22): цена нескольких машин в окне — 8–12 задач.
4. Маршруты субагентов — плагин `advanced-delegation` в поставке, закреплённый по коммиту;
   ключи маршрутов только через провайдера (UR48, C10).
5. Локальная диктовка — faster-whisper, русский, модель скачивается при первом включении,
   умолчание по замеру на записях владельца (UR49).
6. MCP-сервер Lira Support — в установщике и подключён (UR50); Revit — проверка
   совместимости последней задачей (UR51).
7. A2A и подписанные вебхуки — как в Hermes; дефект подписи — известная особенность (T49).
8. LightRAG 1.5.7, Docling 2.148.0; RapidOCR 3.10 — по бесплатному замеру; sigma 4.
9. Не берём: веб-приложение (HX33), события MCP через вебхуки (HX34), Daybreak и удалённую
   конфигурацию флота (HX35), плагины окна (HX5), менеджеры паролей (HX24), поиск Яндекса в
   поставке, свою кнопку обновления промптов.

## Consequences

- Первая задача этапа — бесплатный замер на v0.23.0: кто владеет комнатами под нашим
  `hermes serve --isolated` и что меняет шлюз `gateway run`, который поднимает тик расписаний
  (решение [0011](0011-schedule-tick-in-main.md)): по коду вызовы комнат уходят к готовому
  шлюзу профиля.
- `aec-roster` остаётся: обращение к специалисту на другой машине идёт им, пока действует HX22.
- `stage_core.py` теряет `agent-browser`; списки инструментов и граница R22 переходят на
  `browser_exec`.
