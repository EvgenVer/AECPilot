# 0012 — Подъём ядра на 0.22.2

- Date: 2026-10-15 (интервью владельца, решения 1–14); 2026-10-16 (решения 15–19)
- Status: accepted (сменяет пин 0.21.5, `f97608f1`)
- Approved by: owner

## Context

После 0.21.5 вышли 0.21.6, 0.21.7, 0.22.0, 0.22.1 и 0.22.2. Окно: 10 362 файла,
+887 тыс. / −258 тыс. строк. Схема выпуска сменилась (стабильные `vX.Y.Z`, рядом rc и
ежедневные canary). Ядро 0.22 требует Python 3.14; Mem0 ушёл из ядра во внешний плагин;
`hermes serve` научился присоединяться к чужому «бэкенду машины».

## Options

### Поднять на `v0.22.2` (`d923a5eb`), venv ядра на Python 3.14, Mem0 ставить самим по пину — chosen

- Advantages: свежий контракт и донор; Mem0 и плагины не ставятся ядром из сети.
- Limitations: новый интерпретатор для нашего слоя (фильтр секретов, Mem0); их русский
  каталог не проверен на качество; `aec-qa` всегда в контексте (дороже ход).
- Cost and effort: фаза 2 (T20.1–T20.15): веттинг, перенос донора (1438 файлов в зоне,
  584 изменились), пробы, приёмка ×3.
- Changing it later: costly.

### Остаться на 0.21.5

- Limitations: отставание растёт; каждый следующий подъём дороже.

## Decision

1. Пин — только стабильный `vX.Y.Z`, rc и canary не используем. 2. Критерий фазы — без
A2A (дефект подписи ждёт апстрим, T49). 3. Python 3.14 для venv ядра; наши MCP остаются на
3.12. 4. Mem0 — плагин 1.3.0 на `43849c6e` ставит `setup.mjs` после веттинга. 5. Умолчанием в
профиле закрыты `security.allow_lazy_installs`, `auth.adopt_external_logins`,
`tools.connectors.enabled`, `telemetry.shared_metrics.*`. 6. Каталог плагинов — только через
наш гейт доверия. 8, 15. `hermes pm` — в упаковку (фаза 3). 9–10. Новинки донора берём,
Simple/Advanced с умолчанием Advanced. 11. Импорт сессий другого агента — не берём (HX30).
12. `skills.auto_load: [aec-qa]`. 13. Русский интерфейс — их каталог плюс наш слой
переопределений. 16. Правка агентом поставляемого навыка идёт в копию в профиле. 17. Сторож
загрузки фильтра секретов: не загрузился — ход не начинается. 18. Уязвимые транзитивные
npm-зависимости обновить с веттингом.

## Consequences

- Профиль получает `plugins.load_timeout_seconds: 120`: импорт бэкенда Mem0 идёт 12,7 с, а
  не уложившийся плагин ядро молча выключает со всеми регистрациями.
- `hermes serve` запускается с `--isolated`.

  задачи — [этап 2](../history/stage-2.md), факты — [core-facts.md](../core-facts.md).
