# 0007 — Роестр специалистов: перенос их плагина, наш `aec-roster` поверх

- Date: 2026-09-01 (SPEC O12, фаза 3D)
- Status: accepted (заменяет решение 2026-08-18 «пишем роестр своим кодом»)
- Approved by: owner

## Context

UR27 требует специалистов — профили ядра с именем, ролью, моделью и памятью, постоянный
чат, групповые чаты, рутины, обращение `@имя`. 2026-08-18 роестр решили писать своим кодом:
их Bot Mode приезжал одним собранным `plugin.js` на 331 КБ, который не ложится под правила
донорской зоны. В 0.21.0 плагин стал 105 файлами исходников с тестами — основание исчезло.

## Options

### Перенести их плагин в донорскую зону, своим `aec-roster` закрыть обращение на другую машину — chosen

- Advantages: их поведение и тесты; наш код роестра (6 285 строк) удаляется; HX1 (питомец)
  снимается правкой регистрации, а не хирургией в бандле.
- Limitations: 37 из 45 файлов импортируют их SDK (`@hermes/plugin-sdk` ведёт в их же
  дерево); три члена `host` (`connections`, `agents`, `profileRoutes`) намеренно без моста —
  «одно подключение за раз» (2026-08-23), их `relay.ts` лежит мёртвым кодом.
- Cost and effort: фаза 3D (11 задач).
- Changing it later: costly.

### Оставить свой роестр

- Limitations: отставание от их плагина и двойная работа на каждом подъёме.

## Decision

Переносим их плагин. Загрузчик сторонних плагинов остаётся выключенным (HX5): их исходники
поднимаются нашей регистрацией, кода с диска мы не исполняем. Обращение к специалисту на
другой машине идёт нашим MCP-инструментом `aec-roster` (одно действие — «спросить
специалиста»), снимок роестра для него пишет главный процесс (`main/roster.ts`).
Серверные комнаты ядра (`groups.*`) не берём (HX18): круг ведёт клиент.

## Consequences

- `mcp/aec_roster/` — сервер с единственным инструментом; список специалистов приходит в
  тексте ошибки, когда имя не найдено.
- SOUL нового специалиста начинается с SOUL главного агента (UR44).
- Разбор и замеры — [plan-details.md](../plan-details.md) §«Переход роестра на перенос
  (фаза 3D)», [контракт](../history/specs/agent-roster.md).
