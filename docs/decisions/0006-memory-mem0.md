# 0006 — Память: записка ядра + Mem0 локально (вариант A)

- Date: 2026-08-31 (гейт фазы 5); с 2026-10-15 Mem0 — внешний плагин (см. [0012](0012-core-0-22-2.md))
- Status: accepted
- Approved by: owner

## Context

У ядра есть встроенная память — две записки `MEMORY.md`/`USER.md` в профиле, целиком в
промпте каждого хода, с настраиваемым пределом. Автоизвлечение фактов у ядра тоже есть
(`background_review`). Вопрос: брать ли второй слой — их провайдера Mem0. Уникального у Mem0
два: поиск по смыслу и дата с сессией-источником у факта. Проектной оси памяти у ядра нет
вовсе: профиль — это человек или специалист, а не проект.

## Options

### Вариант A: Mem0 в режиме `oss`, локальный qdrant файлом, модели — у провайдера пользователя — chosen

- Advantages: поиск фактов по смыслу; без сервера (qdrant встраивается путём); работает
  рядом с записками ядра.
- Limitations: второй векторный движок рядом с NanoVectorDB; без ключа провайдера не
  поднимается вовсе; телеметрия `mem0ai` включена по умолчанию (выключаем кодом); проектный
  скоуп — наша работа целиком; память всех проектов в одном хранилище профиля (R23).
- Cost and effort: 13 пакетов, ~21 МБ колёсами; ~16,5 КБ на факт; до трёх обращений к модели
  на ход.
- Changing it later: easy — провайдер памяти один ключ конфига.

### Только записки ядра

- Advantages: ноль зависимостей, уже работает.
- Limitations: нет поиска по смыслу и источника факта.

### Вариант B: Mem0 на локальной ollama

- Limitations: требует сервер ollama.

## Decision

Берём Mem0 в режиме `oss`: LLM и эмбеддер — через OpenAI-совместимый адрес провайдера
пользователя, хранилище — локальный qdrant в профиле, `MEM0_TELEMETRY=false`. Проекты
разделяются ключом `user_id=project-<хэш>` внутри хранилища профиля. Автозапись включена по
умолчанию, переключатель — в настройках. Решение принято владельцем против исправленной
рекомендации агента («не брать») с полной ценой на руках.

## Consequences

- Наш плагин `aec_secret_filter` отсекает секреты на обоих путях записи в память (инструмент
  и автоматическая запись хода).
- Страница «Память» показывает факты слоя 2 с поиском и удалением, записки ядра — отдельной
  вкладкой (UR43).
- Факты ядра о памяти и методика замера — [core-facts.md](../core-facts.md) §«Фаза 5 —
  память», [контракт](../history/specs/agent-memory.md).
