# 0024 — Диктовка в поставке: модель turbo, пакеты распознавания, GPL-части `av`

- Date: 2026-11-25
- Status: accepted
- Approved by: owner (модель turbo; готовый `av`)

## Context

Диктовку распознаёт код ядра (faster-whisper, дополнение ядра `stt-whisper`). Ему нужна модель
и пакет `av` (PyAV), который распаковывает запись. В готовом колесе `av` лежат libx264 и
libx265 под GPL; сама диктовка ими не пользуется. [PRODUCT](../PRODUCT.md) C3 исключает GPL,
кроме отдельной программы, которую ядро запускает процессом.

## Options

Модель (замер — `eval/reports/dictation.md`): turbo, medium, small. Выбрана turbo: 40–41 из 49
терминов против 36–39 у medium.

`av`:

1. **Своя сборка без GPL** (рекомендация). Собрана и проверена на base: текст тот же, что у
   готового. Плюс — нет GPL. Минус — пересобирать при смене `av` или Python.
2. **Свой распаковщик вместо `av`.** Плюс — мал. Минус — подменяем часть пакета ядра.
3. **Готовый `av` с PyPI** (выбран владельцем). Плюс — ничего не собирать. Минус — обязанности
   GPL и спор с лицензией, ниже.

## Decision

Модель — `dropbox-dash/faster-whisper-large-v3-turbo` (MIT), скачивается с согласия человека.
В поставку ядра входит дополнение `stt-whisper`; `av` — 18.1.1 вместо закреплённой ядром
18.1.0: PyPI отозвал её за двойное освобождение памяти. Готовое колесо `av` берётся как есть,
исключение записано в C3 и N8. О споре ниже владельцу сообщили после выбора; 2026-11-25 он
повторил: свою сборку не делаем, берём готовый.

## Что узнали после выбора

При описании варианта 3 я назвал «обязанности GPL», но не сказал главного: по GPL спор не об
одном `av`. Процесс ядра загружает `av` в тот же Python, где работает наш плагин
`aec-secret-filter`, а AECPilot — закрытая программа (A8). Условия GPL требуют, чтобы программа,
связанная с GPL-библиотекой, раздавалась на условиях GPL. Окно и главный процесс — отдельные
процессы и `av` не загружают, поэтому спорное место — только этот плагин; насколько правило
действует для него — вопрос к юристу. Простой выход, если понадобится, — дать плагину
лицензию, совместимую с GPL (например, MIT); решение о лицензии — за владельцем.
То же правило в 2026-09 остановило `pillow-heif` (те же libx265). Ничего ещё не выпущено.

Состав колеса — по рецепту PyAV-Org/pyav-ffmpeg 8.1.3-1: каждая библиотека с лицензией, ссылкой
на исходники и текстом (`apps/desktop/third-party-licenses/pyav`) попадает в
`THIRD-PARTY-NOTICES.txt` вместе с письменным предложением на три года; незнакомая
библиотека в колесе останавливает сборку. Точные версии libiconv, GCC, winpthreads и zlib
рецепт не называет (берутся из MSYS2 на машине сборки) — для них дана ссылка на исходники
MSYS2.

Ревью 2026-11-25 нашло ещё одно: колесо `ctranslate2` (движок распознавания) несёт
закрытые библиотеки — NVIDIA `cudnn64_9.dll` (удаляется из поставки, распознавание на процессоре
без неё работает) и Intel `libiomp5md.dll` (движок слинкован с ней). Вторая осталась: файл тот же,
что в пакете `intel-openmp` 2025.3.0 (совпал SHA-256), лицензия — Intel EULA for Developer Tools
(August 2024). Она разрешает раздавать перечисленные Intel файлы в составе программы, если
лицензия программы запрещает их разбирать: наш `LICENSE.txt` п. 2 запрещает, текст Intel едет
в поставке. Не сверено: самого перечня (redist.txt) в пакете нет. C3 закрытых библиотек не
называет; отдельного решения владельца о ней нет, ему сообщено 2026-11-25.

## Consequences

- Поставка ядра без модели больше примерно на 200 МБ (распакованные `av`, ctranslate2,
  onnxruntime, tokenizers, huggingface-hub; замер 2026-11-25). Сколько прибавит
  установщику — не мерили.
- Наш плагин просит у Windows полную скорость для процесса ядра (`full_speed.py`): без этого
  процесс без окна уходил на энергосберегающие ядра, и фраза шла 10–27 с вместо 8–10.
- Пакет `huggingface-hub` в поставке нужен faster-whisper; модель скачивает наша программа.
- Телеметрия onnxruntime: переменную `ORT_DISABLE_TELEMETRY`, предложенную ревью, не задаём —
  в библиотеках поставки (1.31.0) такого имени нет, она ничего бы не изменила; адресов отправки
  в них тоже не найдено (поиск по файлам, 2026-11-25). Есть трассировка Windows (ETW): это
  события о работе движка внутри системы, отправку их Windows мы не проверяли. При смене версии
  проверить заново.
