# 0002 — Код Hermes Desktop внутри нашей оболочки

- Date: 2026-08-05 (смена курса, решения D2–D5; правка 6 — 2026-10-06)
- Status: accepted
- Approved by: owner

## Context

Вышел Hermes 0.20.0 с их собственным настольным приложением. Наш интерфейс воспроизводил
их поведение своим кодом и отставал: каждая их новая возможность — наша новая работа.
Владелец сформулировал продуктовый принцип: то, чего продукт не делает, важно не меньше
того, что делает, — значит нужно право выбрасывать их функции.

## Options

### Их UI-стек и их компоненты внутри нашей оболочки — chosen

- Advantages: их скорость (60 fps, виртуализация, 14× стриминг markdown) и их тесты
  приезжают вместе с кодом; новые возможности берутся переносом; право не включать то, что
  исключено, остаётся у нас.
- Limitations: стек без гарантий стабильности (R12) — треть зоны стареет за две недели;
  перенос идёт узлами, а не экранами; правки их файлов ограничены шестью видами.
- Cost and effort: подъём пина = повторный перенос зоны и переналожение правок по
  заголовкам (`runtime/vendor-donor.mjs`, `donor-report.mjs`).
- Changing it later: hard.

### Плагин внутри их приложения

- Advantages: минимум своего кода.
- Limitations: плагин не может убрать ни одной их поверхности — право исключать теряется.
- Changing it later: hard.

### Форк их десктопа

- Advantages: полный контроль над интерфейсом.
- Limitations: вливание их обновлений с перестроенным UI дороже, а не дешевле.
- Changing it later: hard.

## Decision

Приложение остаётся нашим (C8): их код втягивается внутрь нашей оболочки. Берём их стек
целиком — Tailwind v4, shadcn/Radix, nanostores, React Query, Codicon, их форма i18n (D2);
где функционал совпадает, ставим их компонент, наш выбрасываем (D3); внешний вид — их, как
есть (D5). Правило объёма перевёрнуто: берём всё, кроме закрытого списка исключений
[PRODUCT.md](../PRODUCT.md) §«Не входит в первую версию» (D4, UR13).

Их файлы лежат в `apps/desktop/src/renderer/src/donor/**` по `DONOR_SHA = HERMES_SHA` с
заголовком происхождения и ровно шестью разрешёнными видами правок (правила — `AGENTS.md`
§Project rules). Обновление — повторный перенос с нового SHA, не патч.

## Consequences

- Два шима вместо правок их кода: `@hermes/shared` (их клиент шлюза → наш IPC-мост,
  `renderer/src/shared/gateway-bridge.ts`) и `window.hermesDesktop` (прокси над
  `window.aecpilot`, `hermes-desktop-shim.ts`); гейты `void-members.test.ts` и
  `donor-members.test.ts`.
- Наши поверхности (просмотрщики, проводник, индекс, память) — в `renderer/src/aec/**`, тот
  же стек, без заголовка.
- Паритет измеряется скриптами по трём осям — экраны, каналы главного процесса, инструменты
  ядра (`pnpm parity`, AC9).
