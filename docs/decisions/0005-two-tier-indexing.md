# 0005 — Индексация в два уровня; текстовый слой раньше распознавания

- Date: 2026-08-15 (два уровня, UR24); 2026-10-07 (две скорости, UR8)
- Status: accepted
- Approved by: owner

## Context

Граф знаний LightRAG стоит вызова модели на каждый фрагмент (R6) — на реальном проекте это
заметные деньги. Эталонный вопрос «какая установленная мощность по заданию ЭОМ» графа не
требует. Замер 2026-10-07: PDF на 283 страницы разбирался 37 минут целиком, тот же текстовый
слой читается за 2 секунды.

## Options

### Поиск — всегда и без модели; граф — по выбору человека; текстовый слой сразу, OCR в фоне — chosen

- Advantages: чистая установка не тратит ни копейки, пока человек не выбрал документы;
  файл находится поиском через секунды; цена графа видна до запуска.
- Limitations: обзорный ответ по графу покрывает только отмеченное — интерфейс обязан
  показывать, что в графе; текстовый слой файла пишется целиком (остановка посреди чтения —
  файл читается заново).
- Cost and effort: состав графа, очередь распознавания и ошибки по файлам в `index.db`.
- Changing it later: easy — флаг уровня в конвейере.

### Граф для всего проекта по умолчанию

- Limitations: цена по умолчанию, а не по выбору; долго.

### Только векторы

- Limitations: таблица работ в одном фрагменте «размывает» эмбеддинг — нужная строка не
  попала в топ-100 (замер 2026-08-15); без полнотекстового поиска нельзя.

## Decision

Уровень 1, всегда: разбор → фрагменты → векторы + FTS5, ноль вызовов модели при индексации.
Уровень 2, по выбору: граф один на проект, единица выбора — папка или файл, по умолчанию
пуст; механизм — штатный флаг LightRAG `process_options="!"`. Поиск гибридный: векторы и
FTS5 сливаются reciprocal rank fusion. PDF: текстовый слой читается сразу (pdfium), страницы
без пригодного слоя распознаются в фоне RapidOCR (`eslav`) постранично, с продолжением после
остановки. Место в файле (locator) доносится через `chunk_id` и записывается родной
адресацией формата: `p12`, `Ведомость!C5:D6`, `h:Кабельный журнал`.

## Consequences

- Ход индексации и построения графа виден по файлам, страницам и фрагментам; нет общего
  предела по времени — обрывается только процесс, который долго молчит (UR8, D-183).
- Новые файлы в отмеченной для графа папке приходят уведомлением, а не добавляются молча.
- Устройство — [aec-rag](../components/aec-rag.md), сценарий — [индексация](../flows/indexing.md).
