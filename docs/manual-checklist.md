# Ручная приёмка — мигрированный интерфейс (фаза 1.8)

Один прогон на всё. Формат: **что сделать → что увидеть (✓)**.
Докладывайте **только замечания**: молчание по блоку = «прошло».

Перед началом закройте прошлые окна приложения. Осиротевшие процессы Electron
дают «белый экран» — это не баг кода (`MEMORY.md`).

```bash
corepack pnpm dev
```

Что именно проверяется этим прогоном: интерфейс целиком заменён на код Hermes
Desktop, а наши собственные поверхности (проект, проводник, источники, откат)
написаны заново на их стеке. Поэтому чек-лист не про «работает ли кнопка» — он
про то, **не потерялось ли поведение**, которое у нас было измерено, и **не
приехало ли лишнее** из их продукта.

---

## Блок 1. Гейт проекта

1. Запустите приложение без открытого проекта.
   ✓ Видно наш экран выбора проекта, а не их чат.
   ✓ Заголовок «AECPilot», строка «IDE для проектной документации».

2. Нажмите «Создать проект», выберите **непустую** папку с вашими файлами, дайте имя.
   ✓ Проект создаётся; **ни один существующий файл не тронут** — проверьте
     глазами два-три своих файла в этой папке.
   ✓ Приложение переключилось на интерфейс агента.

3. Закройте и откройте приложение снова.
   ✓ Сразу интерфейс агента, без мелькания экрана выбора.

4. Выберите «Открыть проект» и укажите папку, которая проектом не является.
   ✓ Не ошибка, а диалог создания — с уже подставленными папкой и именем.

## Блок 2. Меню проекта (статус-бар)

1. Посмотрите на левый край статус-бара.
   ✓ Видно **имя** открытого проекта, без наведения и без клика.

2. Откройте меню.
   ✓ Полный путь к vault, «Создать проект», «Открыть проект», список недавних
     (текущего в списке нет).

3. Переключитесь на другой проект из недавних.
   ✓ Интерфейс перерисовался под новый проект: имя в статус-баре, дерево
     проводника, список сессий.

## Блок 3. Проводник vault

1. Разверните пару папок.
   ✓ При старте все папки закрыты.
   ✓ `.aecpilot` в дереве не показывается.

2. Наведите на строку → создайте файл, папку, переименуйте, удалите.
   ✓ Перед удалением спрашивают подтверждение.
   ✓ После каждой операции дерево обновилось само.
   ✓ Если операция не удалась — на панели видно **почему**, а не тишина.

3. Правый клик по строке.
   ✓ То же меню действий, плюс «Показать в проводнике».

4. Выделите строку и нажмите Del.
   ✓ Спрашивают подтверждение (Del — сокращение, а не обход).

5. Введите в поле фильтра часть имени файла, лежащего внутри папки.
   ✓ Папка осталась видна и раскрылась сама.
   ✓ Совпадение подсвечено внутри имени.
   ✓ Пустой результат честно говорит «Ничего не найдено».

6. «Показать в проводнике» на файле.
   ✓ Открылся системный проводник с выделенным файлом.

## Блок 4. Источники

1. Подключите папку с документами.
   ✓ Появилась в списке под деревом vault.

2. Подключите папку, **вложенную** в уже подключённую.
   ✓ Приложение предупредило о пересечении и **не подключило** сразу.
   ✓ «Подключить всё равно» подключает; «Отмена» — нет.

3. Разверните источник.
   ✓ Видно его дерево; «Показать в проводнике» работает и здесь.

4. Отключите съёмный диск или сетевую шару, подключённую как источник, и
   подождите очередного скана (или переоткройте проект).
   ✓ У источника виден бейдж «недоступен» — **без разворачивания**.

5. Отключите источник.
   ✓ Спрашивают подтверждение; файлы на диске остаются на месте.

## Блок 5. Детект изменений

1. Добавьте, измените и удалите по файлу в подключённом источнике. Дождитесь скана.
   ✓ Пришло уведомление с разбивкой: сколько добавлено, изменено, удалено.
   ✓ Неизменённые файлы в уведомлении **не упоминаются**.

2. Дождитесь следующего скана, ничего не меняя.
   ✓ Уведомления **нет** (иначе тост на каждом цикле — это шум).

## Блок 6. Чат (их код)

1. Задайте вопрос, на который агент ответит списком, кодом и таблицей.
   ✓ Разметка отрисована; блок кода подсвечен, с кнопками копирования.
   ✓ Пока ответ печатается, недописанная разметка не мигает символами.

2. Дайте задачу, где агент вызовет инструменты.
   ✓ Видны карточки вызовов, рассуждения сворачиваются/разворачиваются.

3. Прервите ответ на середине и напишите следом ещё одно сообщение.
   ✓ Прерывание срабатывает; следующее сообщение уходит.

4. Дайте агенту команду, которая долго выполняется, и посмотрите правую панель.
   ✓ Лента вывода команды идёт потоком, форматирование сохранено.
   ✓ Если агент спросил ввод — ответ из окна доходит (агент не «зависает» на 30 с).

## Блок 7. Настройки и ключи

1. Настройки → провайдеры. Вставьте ключ провайдера.
   ✓ Ключ принят, модели подтянулись.
   ✓ **Кнопки «показать ключ» нигде нет** (ключ читается обратно только вами и
     только из вашего хранилища ОС).

2. Проверьте, что ключ не появился открытым текстом:
   откройте `runtime/dev-profile/.env` в блокноте.
   ✓ Вашего свежего ключа там **нет**.

3. Пройдитесь по разделам настроек.
   ✓ Раздела биллинга/кредитов нет вовсе.
   ✓ Разделов расписаний, внешних каналов, вебхуков, агентов и Command Center нет
     (они за пределами этой фазы).

## Блок 8. Откат (панель «Изменения»)

1. Попросите агента изменить файл в vault. Откройте панель справа.
   ✓ Снимок появился в списке.

2. Выберите снимок.
   ✓ Видно, какие файлы затронуты и построчную разницу.

3. Нажмите «Восстановить всё», прочитайте подтверждение.
   ✓ В тексте названо **что именно** будет перезаписано и что последний ход
     исчезнет из истории.
   ✓ Сказано, что файлы, созданные после снимка, не удаляются.
   ✓ «Отмена» ничего не меняет.

4. Подтвердите восстановление одного файла.
   ✓ Файл вернулся к состоянию из снимка.

5. Если список снимков пуст, хотя агент правил файлы.
   ✓ Панель объясняет причину (где ядро завело снимки), а не показывает пустоту.

## Блок 9. Язык и тема

1. Настройки → язык интерфейса → English, затем обратно.
   ✓ Переключается сразу, без перезапуска; выбор переживает перезапуск.
   ✓ Наши экраны (проект, проводник, источники, откат) переведены полностью.
   ✓ Непереведённые строки их экранов показываются по-английски — это ожидаемо
     до задачи 6.7, отмечайте только совсем нечитаемые места.

2. Переключите тему светлая/тёмная.
   ✓ Меняется всё окно, включая полосы прокрутки и системные элементы.

## Блок 10. Оболочка

1. Потяните границы панелей, сверните и разверните боковые панели.
   ✓ Границы тянутся, размеры переживают перезапуск.

2. Откройте палитру команд.
   ✓ Открывается; команд про питомца (`/pet`, `/hatch`) в ней **нет**.

3. Поработайте в двух сессиях, переключитесь между ними.
   ✓ Сессии переключаются, история каждой на месте.

## Блок 11. Голос (задача 3.7a)

Блок добавлен 2026-08-17: перенос голосового набора закончен, но проверить его
можно только ушами. Нужен микрофон и колонки/наушники.

1. Нажмите кнопку микрофона в поле ввода и скажите одну фразу, потом нажмите ещё раз.
   ✓ Запись начинается **только** после нажатия — до него индикатора нет.
   ✓ Пока идёт запись, виден индикатор с уровнем звука.
   ✓ Сказанное появляется текстом в поле ввода.
   ✗ Если Windows спросит доступ к микрофону — это ожидаемо, разрешите.

2. Включите «читать ответы вслух» и задайте вопрос.
   ✓ Ответ произносится **по-русски** (голос ru-RU-SvetlanaNeural, женский).
   ✓ Речь начинается сама, без нажатий.

3. Пока агент говорит, начните говорить сами.
   ✓ Воспроизведение обрывается сразу, не дожидаясь конца фразы.
   ✓ Сказанное вами становится следующим сообщением — включая первые слова.

4. Включите разговор голосом (Ctrl+B), проведите два-три обмена, потом скажите «стоп».
   ✓ Разговор идёт без нажатий: услышал → ответил → снова слушает.
   ✓ После «стоп» микрофон отпускается: индикатор гаснет и запись не идёт.

5. Закройте окно приложения во время того, как агент говорит.
   ✓ Речь замолкает вместе с окном, ничего не доигрывает в фоне.

Что здесь ожидаемо и замечанием не является: пауза перед началом речи. На
бесплатном провайдере (Edge) фраза синтезируется целиком и только потом звучит;
поток начинается с первого предложения лишь у платных провайдеров
(ElevenLabs / OpenAI / Gemini / xAI), и этот путь на нашей машине не проверялся —
ключа нет.

## Блок 12. Быстрый ввод (задача 3.15)

1. Свернув приложение, нажмите **Ctrl+Shift+Space** из любого другого окна.
   ✓ Появляется узкое окно ввода поверх всех приложений, курсор уже в поле.
   ✗ Если окно не появилось — скажите: скорее всего, аккорд занят другой
     программой, это видно в логе строкой «quick entry off (taken)».

2. Наберите фразу и нажмите Enter.
   ✓ Окно закрывается, главное окно поднимается, ответ идёт в текущей сессии.

3. Повторите, выбрав «в новую сессию».
   ✓ Создаётся новая сессия, вопрос уходит в неё.

4. Вызовите окно и нажмите Esc; затем вызовите снова и щёлкните мимо окна.
   ✓ Оба раза окно исчезает без следа в панели задач.

## Блок 13. Не давать машине уснуть (задача 3.18)

1. Настройки → раздел с переключателем «keep awake» → включите.

2. Откройте обычную командную строку и выполните:

   ```
   powercfg /requests
   ```

   ✓ В разделе SYSTEM указан `aecpilot` (или путь к нему).
   ✓ В разделе DISPLAY его **нет** — экран гаснуть должен, спать не должна машина.

3. Выключите переключатель и повторите команду.
   ✓ Записи об aecpilot больше нет.

4. Включите переключатель, закройте приложение и запустите снова.
   ✓ `powercfg /requests` снова показывает запись — настройка пережила перезапуск
     (иначе ночной прогон после обновления приложения тихо потерял бы защиту).

## Блок 14. Мастер первого запуска (задача 3.20)

Это блок «глазами человека, который видит приложение впервые». Проверять его
надо на **новом** проекте — мастер помнит, что он уже пройден, по пути vault.

1. Создайте новый проект.
   ✓ В правом нижнем углу — панель «С чего начать» со списком из шести шагов.
   ✓ «1. Проект» отмечен галкой; текущий шаг — «Ключ провайдера».

2. Если ключа на машине ещё нет, поверх должен подняться их собственный экран
   подключения провайдера. Нажмите в нём «выберу позже» (или закройте его).
   ✓ Панель мастера на месте, текущий шаг — по-прежнему «Ключ провайдера».

3. Нажмите в мастере «Подключить провайдера».
   ✓ Открывается тот же их экран — мастер не делает своей второй формы для ключа.

4. Пройдите его: ключ → модель.
   ✓ Через несколько секунд первые три шага в мастере отмечены галками сами,
     без перезапуска приложения.

5. Нажмите «Подключить папку», выберите папку с документами.
   ✓ Шаг «Папка с документами» отмечен; текущим стала «Индексация».

6. Нажмите «Проиндексировать».
   ✓ Видно «индексация N / M»; по окончании шаг отмечен галкой.

7. Нажмите «Подставить вопрос».
   ✓ Вопрос появился **в поле ввода**, но НЕ отправлен — отправляете вы, Enter.
   ✓ После этого панель исчезает.

8. Перезапустите приложение с тем же проектом.
   ✓ Панели нет и больше не будет.

9. Создайте ещё один новый проект и на шаге «Папка с документами» нажмите «Позже».
   ✓ Индексация помечена «отложено» и текущим шагом сразу стал «Первый вопрос»
     — кнопки «Проиндексировать», которой нечего делать, человек не видит.
   ✓ Подставленный вопрос ДРУГОЙ: не «перечисли документы» (их нет), а про то,
     что агент вообще умеет.

## Блок 15. Проверка выдержек (задачи 3.30, 3.31)

Агент приводит рядом со ссылкой дословную фразу из документа. Приложение сверяет
её с текстом источника и метит ту, которой там нет. Здесь проверяется, что
пометка появляется тогда и только тогда, когда должна.

1. Задайте вопрос, ответ на который есть в документах.
   ✓ В ответе есть ссылка и выдержка в «ёлочках» рядом с ней.
   ✓ Фишка ссылки обычная — серая, со значком файла.
   ✓ Наведите на неё: в подсказке только сама ссылка, ничего про выдержки.

2. Кликните по фишке.
   ✓ Документ открывается на нужном месте — как и раньше.

3. Теперь заведомо трудный вопрос: спросите про то, чего в документах нет, но
   что похоже на соседний раздел (например, марку стали для конструкции,
   которой в проекте не проектировали).
   ✓ Ответ **начинается** со слов, что этого в документах нет, а найденное
     рядом разбирается после. Ответ, который начинается со значения и
     оговаривается в конце, — это замечание.

4. Проверить саму пометку без подделки ответа трудно, поэтому просто отметьте,
   если увидели её хоть раз за прогон:
   ✓ Жёлтая фишка со значком внимания, в подсказке — сама фраза, которой нет в
     источнике.
   ✓ **Текст ответа при этом не изменён** — приложение ничего не переписывает и
     не вырезает, только помечает.

5. Если пометки не появлялись ни разу — это нормальный исход и замечанием не
   является: значит агент цитировал добросовестно.

## Блок 16. Просмотрщик: вкладки, поиск, масштаб (задача 4.1, AC8)

Просмотрщик — это то, чем проверяют ответ агента. Здесь важно не «красиво», а
три вещи: нужное место открылось, его видно, и открытых документов может быть
несколько.

1. Кликните ссылку в ответе агента на PDF.
   ✓ Документ открылся на странице из ссылки, а не на первой.

2. Кликните вторую ссылку — на другой документ.
   ✓ Сверху появилась полоса вкладок с обоими именами.
   ✓ Первый документ никуда не делся: клик по его вкладке возвращает к нему,
     причём **на ту же страницу**, где вы его оставили.

3. Кликните ссылку на документ, который уже открыт, но на другую страницу.
   ✓ Третьей вкладки не появилось — открытая переехала на новую страницу.

4. Закройте одну вкладку крестиком на ней самой.
   ✓ Закрылась именно она; на экране остался соседний документ.

5. Масштаб: нажмите «+» два-три раза.
   ✓ Лист увеличивается ступенями, проценты показаны на кнопке между «−» и «+».
   ✓ Панель прокручивается — увеличенный лист не обрезан.
   ✓ Клик по кнопке с процентами возвращает «по ширине».

6. Поиск: введите в строку поиска слово, которое точно есть в документе
   (не короче двух букв).
   ✓ Справа от строки — счётчик вида «3 из 17».
   ✓ Просмотрщик сам перешёл на страницу с найденным, и найденное подсвечено
     жёлтым; текущее совпадение ярче остальных.
   ✓ Стрелки ↑ ↓ (и Enter / Shift+Enter) ходят по совпадениям, страница
     меняется вместе с ними.

7. Введите слово, которого в документе нет.
   ✓ Написано «Совпадений нет». Страница при этом **не** уехала.

8. Ищите слово, разорванное переносом строки (например, начало на одной строке,
   конец на следующей) или словосочетание из двух слов через перенос.
   ✓ Находится. Это главная проверка блока: наивный поиск по PDF здесь и
     ломается.

9. Переключитесь на другую вкладку.
   ✓ Строка поиска пуста — запрос от прошлого документа не перенёсся.

10. Битый файл: возьмите любой .pdf, откройте его блокнотом, испортите первые
    строки, сохраните и откройте из проводника vault.
    ✓ Понятное сообщение об ошибке с путём к файлу.
    ✓ **Приложение не упало и не зависло** — остальные вкладки живы.

## Блок 17. DOCX и TXT (задачи 4.2, 4.2a, AC8)

1. В проводнике vault кликните по любому файлу (не по папке).
   ✓ Он открылся во вкладке просмотрщика. Раньше документ открывался только из
     ссылки в ответе агента — теперь и просто из дерева.

2. То же в панели источников: разверните источник и кликните файл.
   ✓ Открылся. Правки нет и не предлагается — источники только для чтения.

3. Откройте .docx.
   ✓ Виден документ, а не текст без оформления: заголовки, таблицы, отступы.
   ✓ Лист белый даже в тёмной теме — так и задумано, документ выглядит как на
     печати.
   ✓ Страницы разделены, как в Word.

4. Откройте .txt, набранный **в кириллице и сохранённый в Windows-1251**
   (годится любая старая выгрузка из расчётной программы; в блокноте это
   кодировка «ANSI»).
   ✓ Русский текст читается. **Кракозябры («Êàáåëü») — это замечание**, и
     главное в этом блоке.
   ✓ Справа в шапке подписано `windows-1251`.

5. Откройте .txt в UTF-8.
   ✓ Читается, в шапке подписано `UTF-8`.

6. Битый .docx: возьмите любой .docx, испортите его блокнотом, сохраните,
   откройте.
   ✓ Понятная ошибка с путём, приложение живо.

## Блок 18. Таблицы: XLSX и CSV (задача 4.3, AC8)

1. Откройте .xlsx из проводника (любая ведомость с несколькими листами).
   ✓ Видна таблица с номерами строк слева.
   ✓ Листы книги — кнопками над таблицей; переключение работает.
   ✓ **Объединённый заголовок написан один раз**, а не повторён в каждой
     ячейке, которую он накрывает.

2. Найдите в книге ячейку с датой и ячейку с формулой.
   ✓ Дата показана датой (`2026-08-17`), а не числом вроде 46251.
   ✓ У формулы показано её **значение**, а не текст `=A1+B1`.

3. Большая ведомость (если есть — от нескольких тысяч строк).
   ✓ Прокручивается без рывков.
   ✓ Если строк больше 20 000 — в шапке подписано «Первые 20000 строк из …».
     Молча обрезанной таблицы быть не должно.

4. Откройте .csv, сохранённый **русским Excel** (разделитель — точка с запятой,
   дробные числа через запятую: `ВВГнг;2,5;13,4`).
   ✓ Три колонки, а не пять. Если «2,5» разъехалось на две ячейки — замечание,
     и это главная проверка блока.

5. Откройте .csv с запятой-разделителем.
   ✓ Тоже разобрался правильно — разделитель определяется по файлу.

6. Кириллический .csv в кодировке Windows-1251.
   ✓ Читается без кракозябр.

## Блок 19. Ссылка приводит на место, а не на файл (задача 4.4, AC1)

Это главная проверка вьюеров: цитата обещает не документ, а место в нём.

1. Задайте вопрос, ответ на который лежит в **таблице**.
   ✓ В ссылке видно что-то вида `ведомость.xlsx, Ведомость!C5`.
   ✓ Клик открывает книгу **на названном листе**, а не на первом.
   ✓ Названные ячейки подсвечены жёлтым, и таблица прокручена к ним.

2. Кликните ту же ссылку ещё раз, предварительно уехав прокруткой в другое
   место листа.
   ✓ Вернуло к тому же месту.

3. Вопрос, ответ на который лежит в **DOCX**.
   ✓ В ссылке видно название раздела (`ПЗ.docx, Кабельный журнал`).
   ✓ Клик открывает документ и **прокручивает к этому разделу**, заголовок
     подсвечен.
   ✓ Если раздел не нашёлся — документ открыт с начала. Это допустимо;
     замечание — если он прокрутился к **чужому** месту.

4. Ссылка без указания места (просто имя файла).
   ✓ Файл открывается с начала, ничего не подсвечено.

## Блок 20. Правка .md (задача 4.5)

1. Кликните любой .md в проводнике vault.
   ✓ Открылся редактор: заголовки крупные, списки — списками, а не текст с
     решётками.

2. Поставьте курсор в текст и наберите пару слов.
   ✓ Через секунду в шапке мелькает «Сохраняю…», потом «Сохранено».

3. Переключитесь на другую вкладку **сразу после набора**, не дожидаясь секунды.
   ✓ Вернитесь — набранное на месте. Уход не должен стоить последней правки.

4. Закройте приложение, откройте заново, откройте тот же файл.
   ✓ Правка на диске.

5. Ctrl+Z несколько раз.
   ✓ Отменяет по шагам. Ctrl+Shift+Z (или Ctrl+Y) возвращает.

6. Наберите таблицу в разметке GFM (`| а | б |` и строка из дефисов).
   ✓ Стала таблицей.

7. Откройте .md **из источника** (не из vault).
   ✓ Показан как обычный текст, править нельзя. Источники только для чтения —
     возможность править чужой файл здесь была бы замечанием.

Одной строкой: **где** (блок и шаг), **что сделали**, **что увидели**, **что
ожидали**. Скриншот — если расхождение визуальное.
