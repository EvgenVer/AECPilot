# Ручная приёмка — мигрированный интерфейс (фаза 1.8)

Один прогон на всё. Формат: **что сделать → что увидеть (✓)**.
Докладывайте **только замечания**: молчание по блоку = «прошло».

Перед началом закройте прошлые окна приложения. Осиротевшие процессы Electron
дают «белый экран» — это не баг кода (`MEMORY.md`).

```bash
corepack pnpm dev
```

Что именно проверяется этим прогоном: интерфейс целиком заменён на код Hermes
Desktop, а наши собственные поверхности (проект, проводник, источники, откат)
написаны заново на их стеке. Поэтому чек-лист не про «работает ли кнопка» — он
про то, **не потерялось ли поведение**, которое у нас было измерено, и **не
приехало ли лишнее** из их продукта.

---

## Блок 1. Гейт проекта

1. Запустите приложение без открытого проекта.
   ✓ Видно наш экран выбора проекта, а не их чат.
   ✓ Заголовок «AECPilot», строка «IDE для проектной документации».

2. Нажмите «Создать проект», выберите **непустую** папку с вашими файлами, дайте имя.
   ✓ Проект создаётся; **ни один существующий файл не тронут** — проверьте
     глазами два-три своих файла в этой папке.
   ✓ Приложение переключилось на интерфейс агента.

3. Закройте и откройте приложение снова.
   ✓ Сразу интерфейс агента, без мелькания экрана выбора.

4. Выберите «Открыть проект» и укажите папку, которая проектом не является.
   ✓ Не ошибка, а диалог создания — с уже подставленными папкой и именем.

## Блок 2. Меню проекта (статус-бар)

1. Посмотрите на левый край статус-бара.
   ✓ Видно **имя** открытого проекта, без наведения и без клика.

2. Откройте меню.
   ✓ Полный путь к vault, «Создать проект», «Открыть проект», список недавних
     (текущего в списке нет).

3. Переключитесь на другой проект из недавних.
   ✓ Интерфейс перерисовался под новый проект: имя в статус-баре, дерево
     проводника, список сессий.

## Блок 3. Проводник vault

1. Разверните пару папок.
   ✓ При старте все папки закрыты.
   ✓ `.aecpilot` в дереве не показывается.

2. Наведите на строку → создайте файл, папку, переименуйте, удалите.
   ✓ Перед удалением спрашивают подтверждение.
   ✓ После каждой операции дерево обновилось само.
   ✓ Если операция не удалась — на панели видно **почему**, а не тишина.

3. Правый клик по строке.
   ✓ То же меню действий, плюс «Показать в проводнике».

4. Выделите строку и нажмите Del.
   ✓ Спрашивают подтверждение (Del — сокращение, а не обход).

5. Введите в поле фильтра часть имени файла, лежащего внутри папки.
   ✓ Папка осталась видна и раскрылась сама.
   ✓ Совпадение подсвечено внутри имени.
   ✓ Пустой результат честно говорит «Ничего не найдено».

6. «Показать в проводнике» на файле.
   ✓ Открылся системный проводник с выделенным файлом.

## Блок 4. Источники

1. Подключите папку с документами.
   ✓ Появилась в списке под деревом vault.

2. Подключите папку, **вложенную** в уже подключённую.
   ✓ Приложение предупредило о пересечении и **не подключило** сразу.
   ✓ «Подключить всё равно» подключает; «Отмена» — нет.

3. Разверните источник.
   ✓ Видно его дерево; «Показать в проводнике» работает и здесь.

4. Отключите съёмный диск или сетевую шару, подключённую как источник, и
   подождите очередного скана (или переоткройте проект).
   ✓ У источника виден бейдж «недоступен» — **без разворачивания**.

5. Отключите источник.
   ✓ Спрашивают подтверждение; файлы на диске остаются на месте.

## Блок 5. Детект изменений

1. Добавьте, измените и удалите по файлу в подключённом источнике. Дождитесь скана.
   ✓ Пришло уведомление с разбивкой: сколько добавлено, изменено, удалено.
   ✓ Неизменённые файлы в уведомлении **не упоминаются**.

2. Дождитесь следующего скана, ничего не меняя.
   ✓ Уведомления **нет** (иначе тост на каждом цикле — это шум).

## Блок 6. Чат (их код)

1. Задайте вопрос, на который агент ответит списком, кодом и таблицей.
   ✓ Разметка отрисована; блок кода подсвечен, с кнопками копирования.
   ✓ Пока ответ печатается, недописанная разметка не мигает символами.

2. Дайте задачу, где агент вызовет инструменты.
   ✓ Видны карточки вызовов, рассуждения сворачиваются/разворачиваются.

3. Прервите ответ на середине и напишите следом ещё одно сообщение.
   ✓ Прерывание срабатывает; следующее сообщение уходит.

4. Дайте агенту команду, которая долго выполняется, и посмотрите правую панель.
   ✓ Лента вывода команды идёт потоком, форматирование сохранено.
   ✓ Если агент спросил ввод — ответ из окна доходит (агент не «зависает» на 30 с).

## Блок 7. Настройки и ключи

1. Настройки → провайдеры. Вставьте ключ провайдера.
   ✓ Ключ принят, модели подтянулись.
   ✓ **Кнопки «показать ключ» нигде нет** (ключ читается обратно только вами и
     только из вашего хранилища ОС).

2. Проверьте, что ключ не появился открытым текстом:
   откройте `runtime/dev-profile/.env` в блокноте.
   ✓ Вашего свежего ключа там **нет**.

3. Пройдитесь по разделам настроек.
   ✓ Раздела биллинга/кредитов нет вовсе.
   ✓ Разделов расписаний, внешних каналов, вебхуков, агентов и Command Center нет
     (они за пределами этой фазы).

## Блок 8. Откат (панель «Изменения»)

1. Попросите агента изменить файл в vault. Откройте панель справа.
   ✓ Снимок появился в списке.

2. Выберите снимок.
   ✓ Видно, какие файлы затронуты и построчную разницу.

3. Нажмите «Восстановить всё», прочитайте подтверждение.
   ✓ В тексте названо **что именно** будет перезаписано и что последний ход
     исчезнет из истории.
   ✓ Сказано, что файлы, созданные после снимка, не удаляются.
   ✓ «Отмена» ничего не меняет.

4. Подтвердите восстановление одного файла.
   ✓ Файл вернулся к состоянию из снимка.

5. Если список снимков пуст, хотя агент правил файлы.
   ✓ Панель объясняет причину (где ядро завело снимки), а не показывает пустоту.

## Блок 9. Язык и тема

1. Настройки → язык интерфейса → English, затем обратно.
   ✓ Переключается сразу, без перезапуска; выбор переживает перезапуск.
   ✓ Наши экраны (проект, проводник, источники, откат) переведены полностью.
   ✓ Непереведённые строки их экранов показываются по-английски — это ожидаемо
     до задачи 6.7, отмечайте только совсем нечитаемые места.

2. Переключите тему светлая/тёмная.
   ✓ Меняется всё окно, включая полосы прокрутки и системные элементы.

## Блок 10. Оболочка

1. Потяните границы панелей, сверните и разверните боковые панели.
   ✓ Границы тянутся, размеры переживают перезапуск.

2. Откройте палитру команд.
   ✓ Открывается; команд про питомца (`/pet`, `/hatch`) в ней **нет**.

3. Поработайте в двух сессиях, переключитесь между ними.
   ✓ Сессии переключаются, история каждой на месте.

## Блок 11. Голос (задача 3.7a)

Блок добавлен 2026-08-17: перенос голосового набора закончен, но проверить его
можно только ушами. Нужен микрофон и колонки/наушники.

1. Нажмите кнопку микрофона в поле ввода и скажите одну фразу, потом нажмите ещё раз.
   ✓ Запись начинается **только** после нажатия — до него индикатора нет.
   ✓ Пока идёт запись, виден индикатор с уровнем звука.
   ✓ Сказанное появляется текстом в поле ввода.
   ✗ Если Windows спросит доступ к микрофону — это ожидаемо, разрешите.

2. Включите «читать ответы вслух» и задайте вопрос.
   ✓ Ответ произносится **по-русски** (голос ru-RU-SvetlanaNeural, женский).
   ✓ Речь начинается сама, без нажатий.

3. Пока агент говорит, начните говорить сами.
   ✓ Воспроизведение обрывается сразу, не дожидаясь конца фразы.
   ✓ Сказанное вами становится следующим сообщением — включая первые слова.

4. Включите разговор голосом (Ctrl+B), проведите два-три обмена, потом скажите «стоп».
   ✓ Разговор идёт без нажатий: услышал → ответил → снова слушает.
   ✓ После «стоп» микрофон отпускается: индикатор гаснет и запись не идёт.

5. Закройте окно приложения во время того, как агент говорит.
   ✓ Речь замолкает вместе с окном, ничего не доигрывает в фоне.

Что здесь ожидаемо и замечанием не является: пауза перед началом речи. На
бесплатном провайдере (Edge) фраза синтезируется целиком и только потом звучит;
поток начинается с первого предложения лишь у платных провайдеров
(ElevenLabs / OpenAI / Gemini / xAI), и этот путь на нашей машине не проверялся —
ключа нет.

## Что писать в замечании

Одной строкой: **где** (блок и шаг), **что сделали**, **что увидели**, **что
ожидали**. Скриншот — если расхождение визуальное.
