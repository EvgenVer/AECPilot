## Блок 4. Диагностика «карточки хода пропадают» (задача 1.6.2)

Это **сбор доказательства**, а не проверка. Дефект из вашего прогона 26.07 не
воспроизводится на модельном потоке событий (e2e-тест это проверяет), поэтому
нужен реальный поток.

5. Откройте консоль разработчика: **Ctrl+Shift+I** → вкладка Console.
6. Задайте вопрос, на который агент точно вызовет инструмент (например
   «прочитай файл X и перескажи»), дождитесь конца ответа.
   ✓ В консоли идут строки двух видов:
     `[aecpilot] evt tool.start #call_…` — поток событий шлюза;
     `[aecpilot] лента: сообщений N, инструментов N, рассуждений N` — что
     реально лежит в ленте после каждого изменения.
7. **Если карточки пропали с экрана** — посмотрите ПОСЛЕДНЮЮ строку «лента:».
   - Счётчики не упали (инструментов ≥ 1) → карточки на месте, их прячет
     представление (прокрутка/обрезка) — это одна причина.
   - Счётчики упали до нуля → их удаляет событие, которого мы не ждём; тогда
     нужны последние 10–15 строк `evt …` перед падением.

Пришлите скриншот или текст консоли — по нему причина определяется однозначно,
без гадания. Содержимого сообщений в логе нет (только типы событий и id
инструментов) — это правило секретов спеки.

## Блок 12. Сессии, профили, палитра и YOLO (задачи 1.6.B5.*)

Всё, кроме палитры и молнии, — в активности «Агент» на левой рельсе. Порядок

## Блок 13. Терминал агента, процессы и уведомления (задачи 1.6.B6.*)

Три поверхности: вкладки **«Терминал»** и **«Процессы»** в нижней панели и
уведомления (всплывающие карточки в правом нижнем углу + кнопка «Уведомления»
со счётчиком в статус-баре).

**Чего в приложении НЕТ намеренно** — чтобы не искать: интерактивной оболочки
(во вкладке «Терминал» нельзя вводить команды — она только показывает вывод
агента, решение 1), вкладки предпросмотра с встроенным браузером (решение 2),
голосового ввода и кнопки микрофона (решение 3), уведомлений Windows поверх
других окон (решение 4 — уведомления живут внутри приложения).

Чтобы поверхностям было что показывать, попросите агента запустить что-то
фоновое и достаточно долгое, например: «Запусти в фоне команду, которая
считает до 60 с паузой в секунду, и не жди её завершения».
