# Глоссарий

Термины документации в полном объёме. Короткие определения тех же терминов всплывают при
наведении на слово на любой странице (`docs/.terms.md`).

## Латиница

**A2A** — протокол «агент — агенту»: внешний агент обращается к нашему агенту по сети.
Внешний канал, выключен по умолчанию (UR19).

**AGENTS.md проекта** — файл в корне папки проекта с правилами для агента в этом проекте;
ядро добавляет его в контекст каждой сессии проекта. Создаётся из шаблона
`runtime/templates/AGENTS.md`. Не путать с `AGENTS.md` репозитория — правилами для
агентов-разработчиков.

**aec-qa** — навык ответа по документам проекта: только по найденному, каждое утверждение
со ссылкой на место в файле ([расширения ядра](components/core-extensions.md)).

**aec-rag** — наш MCP-сервер и командная строка: индекс документов проекта, гибридный
поиск с цитатами, граф знаний, сверка выдержек, вики ([страница](components/aec-rag.md)).

**aec-roster** — наш MCP-сервер с одним инструментом: спросить специалиста по имени.

**aec-sources** — наш MCP-сервер чтения папок источников; инструментов записи в нём нет
([страница](components/aec-sources.md)).

**aec-wiki** — навык ведения вики проекта; адаптация навыка `llm-wiki` ядра.

**Docling** — библиотека разбора документов (IBM, MIT); у нас разбирает DOCX, XLSX и CSV.

**FTS5** — полнотекстовый поиск, встроенный в SQLite: находит фрагменты по точным словам,
маркам и обозначениям, которые поиск по смыслу пропускает.

**HERMES_HOME** — переменная окружения, указывающая ядру каталог профиля; см. «Профиль
ядра».

**IPC** — межпроцессное взаимодействие Electron: окно вызывает главный процесс по имени
канала (`ipcRenderer.invoke('gateway:rpc', …)`), главный отвечает.

**JSON-RPC** — протокол вызовов «метод + параметры → результат или ошибка» в формате JSON.
Шлюз ядра говорит на нём поверх WebSocket.

**LightRAG** — библиотека индекса для поиска с генерацией (HKU, MIT): хранит векторы
фрагментов и граф знаний в файлах внутри `.aecpilot/lightrag/`.

**MCP (Model Context Protocol)** — открытый протокол, по которому агент получает
инструменты от внешних серверов. Ядро запускает наши MCP-серверы дочерними процессами и
говорит с ними через стандартные ввод и вывод (stdio).

**Mem0** — библиотека долговременной памяти агента: факты с датой и поиск по смыслу,
локальное хранилище qdrant в профиле. Подключена внешним плагином ядра.

**NSIS** — система сборки установщиков Windows; electron-builder строит на ней установщик
AECPilot.

**OCR** — распознавание текста на изображении; у нас — страниц PDF без текстового слоя
(RapidOCR).

**payload** — заранее собранная переносимая среда, которая едет в установщике: ядро с его
Python и инструментами (`runtime/core`) и наш Python для MCP-серверов (`runtime/mcp`).

**PM** — менеджер пакетов ядра: собирает переносимую среду ядра (интерпретатор, зависимости,
инструменты) для поставки.

**preload** — скрипт Electron, который выполняется в окне до кода страницы и публикует
ограниченный API (`window.aecpilot`) поверх IPC.

**RapidOCR** — движок распознавания текста на onnxruntime; используем модель `eslav`
(восточнославянские языки).

**RRF (reciprocal rank fusion)** — слияние нескольких ранжированных списков: каждый
результат получает сумму `1 / (60 + место)` по спискам. Сливает поиск по векторам и
полнотекстовый.

**safeStorage** — шифрование Electron средствами ОС (на Windows — DPAPI учётной записи
пользователя). Им шифруются ключи провайдеров и токены подключения.

**SOUL.md** — файл профиля ядра с личностью агента, который ядро ставит в начало контекста.
По умолчанию — наш: помощник инженера-конструктора.

**SSH-туннель** — проброс порта поверх SSH: порт на ноутбуке ведёт к порту на сервере, а
шифрование и проверку личности даёт SSH.

**vault** — папка проекта: заметки, вики, черновики и служебная `.aecpilot/` с индексом.

## Кириллица

**Вики проекта** — страницы о сущностях, понятиях и сравнениях проекта, которые агент
ведёт по навыку `aec-wiki` в папке `wiki/`.

**Главный процесс** — процесс Node.js приложения Electron: запускает ядро, держит
соединение с ним, работает с файлами и ключами ([страница](components/main-process.md)).

**Граф знаний** — сущности и связи между ними, извлечённые моделью из выбранных документов;
второй, платный уровень индексации.

**Донор** — Hermes Desktop, настольное приложение авторов ядра; его код взят в наш
интерфейс.

**Зона донора** — папка `apps/desktop/src/renderer/src/donor/` с файлами донора, которые
меняются только шестью разрешёнными видами правок.

**Индекс** — документы проекта, разобранные на фрагменты, с полнотекстовым индексом и
векторами; первый уровень индексации.

**Источник** — подключённая к проекту папка исходных данных; агенту доступна только на
чтение.

**Локатор** — место внутри документа, на которое указывает цитата: страница PDF (`p12`),
лист и диапазон ячеек (`Ведомость!C5:D6`), заголовок (`h:Кабельный журнал`).

**Навык (skill)** — пакет инструкций агенту по стандарту agentskills.io: файл `SKILL.md` и,
при необходимости, скрипты.

**Окно (рендерер)** — процесс Electron, который рисует интерфейс на React; ни с чем внешним
не говорит само ([страница](components/renderer.md)).

**Пин** — точная версия ядра, закреплённая коммитом git (`HERMES_SHA`). **Подъём пина** —
переход на новую версию ядра с измерением изменений.

**Профиль ядра** — каталог `HERMES_HOME`: конфиг, сессии, память, навыки и плагины одного
агента или специалиста.

**Сервер / клиент** — режимы установки: машина с документами и ядром без окна / только окно,
подключённое к серверу.

**Снимок (checkpoint)** — копия файлов, которую ядро делает перед правкой агентом; по ней
панель «Изменения» откатывает правку.

**Специалист** — профиль ядра с именем, ролью, моделью и памятью, к которому обращаются
`@имя`.

**Фрагмент (чанк)** — кусок документа до 2 000 знаков с локатором; единица поиска.

**Цитата (ссылка)** — `[src: <источник>/<путь>#<место>]` в ответе агента; окно показывает её
кнопкой, открывающей документ на этом месте.

**Шлюз ядра** — `hermes serve`: процесс ядра, принимающий JSON-RPC по WebSocket и REST на
127.0.0.1 с токеном.

**Эвал** — повторяемая проверка поведения агента на наборе вопросов с ожидаемыми ответами;
идёт на живой модели и стоит денег.

**Эмбеддинг** — вектор чисел, выражающий смысл текста; близкие по смыслу тексты дают
близкие векторы. Модель эмбеддингов — часть индекса: векторы одной модели бессмысленны для
другой.

**Ядро** — агентное ядро hermes-agent (Nous Research, MIT), которое приложение запускает
отдельным процессом ([страница](components/core-runtime.md)).
