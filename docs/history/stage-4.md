# Этап 4 — доска агентов и управление программами

Закрыт 2026-11-16 без реализации — решение владельца. Этап записывали до версии 0.2; к его
закрытию задачи потеряли смысл:

- **T44** (доска агентов) — сделана раньше, поглощена задачей 3E.13 (2026-09-08).
- **T45** (кто раздаёт задачи доски агентам) — снята: с T53 приложение работает на едином
  шлюзе ядра (решение [0017](../decisions/0017-single-gateway.md)), а у шлюза есть встроенный
  диспетчер доски — настройка `kanban.dispatch_in_gateway`, по умолчанию ядра включена, у нас
  не переопределена. Живым прогоном раздача задач не проверялась.
- **T46** (Command Center и экран агентов) — исключена: специалисты заводятся профилями и
  работают в комнатах (T53); отдельный экран не нужен.
- **T47–T48** (управление программами через экран, UR15) — исключены вместе с UR15: с Revit
  агент работает через MCP-сервер Autodesk (T62), с Lira — через её сервер (UR50, T61).
- **T49** — перенесена в этап 5 как T60.
