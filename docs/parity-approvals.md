# Сверка карточек approvals и уточнений с донорскими (задача 1.6.12)

Что сверялось: наши `ApprovalCard.tsx` / `ClarifyCard.tsx` (+ соседние `SudoCard.tsx`,
`SecretCard.tsx`, ветки `approval.*` / `clarify.*` / `interactive.*` в `chat-state.ts`)
против донорских `apps/desktop/src/components/assistant-ui/tool/approval.tsx`,
`clarify-tool.tsx`, `store/prompts.ts`, `store/clarify.ts` и серверной стороны
(`tools/approval.py`, `tui_gateway/server.py`).

Донорский код здесь — **спецификация для чтения**, не исходник для копирования: их
компоненты написаны на Tailwind + Radix, у нас обычный CSS в `styles/shell.css`.
Расхождения в разметке и в стеке компонентов сами по себе в таблицу не выносятся —
только расхождения в **поведении**.

Вердикт каждой строки: **совпадает** / **устранено** / **осознанное расхождение**.

## 4. Чего не хватило фактов

- **Stop/прерывание хода.** У них третья точка сброса блокирующих карточек — кнопка Stop
  (`session.interrupt`). В нашем доке кнопки остановки хода пока нет, метод шлюза мы для
  этой задачи не подключали. Когда она появится, к ней нужно добавить тот же сброс
  (`approvals: []`, `interactive: []`).
- **Обратный отсчёт до таймаута.** Ни сервер, ни их клиент не сообщают оставшееся время;
  выдумывать таймер по константе (300 с / 120 с) мы не стали.
