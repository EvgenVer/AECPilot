## Подготовка

1. Убить остатки Electron:

```bash
Get-Process electron -ErrorAction SilentlyContinue | Stop-Process -Force
```

2. Запустить (один раз, один терминал):

```bash
$env:AEC_SHOW_WELCOME=1; corepack pnpm dev
```

Должно открыться **ровно одно** окно с экраном Welcome. Если больше — закрыть все,
повторить шаг 1.

## Блок B — Инициализация в непустой папке (1.5.4)

Ключевой сценарий безопасности данных — **файлы пользователя не должны быть перезаписаны**.

1. Создать папку с парой своих файлов (например `test-init\мой.txt`, `test-init\AGENTS.md`
   со своим текстом).
2. «Создать проект» → выбрать эту папку.
3. Ожидаемо: предупреждение о конфликте (`AGENTS.md` уже есть) с запросом подтверждения —
   **без** молчаливой перезаписи.
4. Подтвердить инициализацию.
5. Проверить в проводнике Windows: `мой.txt` цел, `AGENTS.md` **не изменён** (открыть и
   сверить текст), рядом добавилась структура vault и папка `.aecpilot`.
6. Повторно «Создать проект» на той же папке → сообщение, что это уже проект.

## Блок D — Источники внутри проводника (1.5.5)

1. Добавить источник (папку с документами) через менеджер источников.
2. В проводнике: секция «Источники» **под** деревом vault, у источника бейдж read-only.
3. Развернуть источник → дерево его файлов подгружается.
4. ПКМ на **вложенном** узле источника → только «Показать в проводнике» и «Копировать
   путь» (никаких переименовать/удалить/создать).
5. «Копировать путь» → вставить в блокнот, путь корректный.
6. Проверка бага «hover за контуром»: сразу после запуска провести мышью по длинным
   именам — подсветка строки **не** выходит за границу панели.
7. Проверка карточек: в менеджере источников кнопки «Отключить»/«Обновить» **не наезжают**
   друг на друга и не выходят за карточку.
8. Live-статус: отключить/переименовать папку источника на диске → после скана карточка
   показывает «недоступен» **без** перезапуска приложения.

## Блок F — Тулбар и поиск по дереву (1.5.6)

1. В тулбаре проводника — иконки (создать файл / создать папку / обновить), у каждой
   подсказка при наведении.
2. Ввести в поиск часть имени файла → дерево фильтруется, совпадение **подсвечено**.
3. Проверить, что папка-предок видна, если совпадение внутри неё.
4. Крестик очищает поиск, дерево возвращается.
5. Пункт на визуальную проверку владельца: совпадают ли тулбар-иконки с макетом.

## Блок G — Ресайз панелей (1.5.9)

1. Потянуть границу между проводником и центром → ширина меняется, панели не «дёргаются».
2. Потянуть границу чата справа → аналогично.
3. Попробовать утянуть в крайние положения → ширина упирается в пределы (проводник
   180–480, чат 300–600), ничего не ломается.
4. Кликнуть на разделитель и нажимать `←`/`→` → ширина меняется с клавиатуры.
5. **Закрыть приложение и запустить снова → размеры сохранились.**

## Блок H — Тёмная тема (1.5.10)

1. Настройки → тумблер темы → тёмная.
2. Пройти **все** экраны: Welcome, оболочка, проводник, менеджер источников, чат,
   настройки, контекстное меню, тост.
3. Искать: нечитаемый текст, белые «пробоины», невидимые границы, потерянные иконки.
4. Перезапустить приложение → тема сохранилась и применилась **без вспышки** светлой.

## Блок I — Тост изменений после скана (1.5.8)

1. Изменить файлы в источнике (добавить/удалить пару) → дождаться скана.
2. Появится тост с изменениями.
3. Ожидаемо: две кнопки **в столбик**, на всю ширину тоста, текст «Обновить индекс
   (re-ingest)» **не выходит** за границу.
4. Проверить в обеих темах.

## Блок K — Агент видит новый источник без переоткрытия (1.5.1)

1. В **одной** сессии чата спросить агента что-нибудь по источникам.
2. Не перезапуская приложение и не создавая новую сессию — добавить новый источник.
3. Спросить агента про файл из **нового** источника.
4. Ожидаемо: агент его **видит** (это и был баг — раньше требовалось переоткрытие).
5. Удалить источник → агент перестаёт его видеть в той же сессии.

## Блок L — Смена проекта на живой сессии (1.20)

1. Открыть проект A, поговорить с агентом (чтобы была история).
2. Переключиться на проект B: чат **чистый**, источники — от B, история сессий — от B.
3. Вернуться в A: история A на месте.
4. Отдельно: переключить проект **во время стрима ответа** → обрыв старого ответа
   ожидаем, приложение не падает.

## Блок M — Сетевая шара UNC (из спеки, тестами не эмулируется)

дерево и поведение при отсутствии прав (понятная ошибка, не краш).

## Как докладывать

По каждому блоку достаточно: **ок** / **не ок + что увидел** (скриншот помогает).

Блоки, которые проверяются именно глазом владельца и тестами не покрываются: **F**
(иконки vs макет), **D.6–D.7** (визуальные баги hover/кнопок), **H** (тема сквозь
экраны), **I** (вёрстка тоста).

Секрет/sudo (задача 1.5.D1/D1.8) в чек-листе намеренно нет: внешних сервисов с токенами
в MVP нет, а sudo на Windows не встречается — спровоцировать в реальном ходе практически
невозможно.
